# Info screen fonts

Bitmap fonts for the info screen in Adafruit GFX format, generated by
`tools/gfxfont.py` at exact pixel sizes (1-bit, hinted, ASCII only):

| File | Font | Size |
|---|---|---|
| `SansBold28.h` | Noto Sans Bold | 28 px |
| `Sans17.h` | Noto Sans Regular | 17 px |
| `Sans15.h` | Noto Sans Regular | 15 px |
| `SansBold15.h` | Noto Sans Bold | 15 px |
| `SansBold14.h` | Noto Sans Bold | 14 px |

Noto Sans was picked from a side-by-side test of open fonts rendered as 1-bit pixels at
these sizes (it stays the most even). To regenerate, download Noto Sans (static
Regular and Bold TTFs, e.g. from Google Fonts) and run, for example:

```sh
python tools/gfxfont.py NotoSans-Regular.ttf 17 Sans17 src/fonts/Sans17.h
```
